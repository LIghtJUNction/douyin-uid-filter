# v0.1.1 预发布候选

- 支持多个数字 UID，每行一个，自动清理空白行、去重；任一目标命中即保留。旧单 UID 自动保留，首次保存后使用新配置格式。
- 主评论、已加载回复及可见计数共用多 UID 配置；切换、删除或关闭后重新进入评论区。
- 在抖音已有的标准 Android 选项菜单中尝试提供「UID 评论过滤」设置入口；自定义评论区菜单不强行注入。看不到时从桌面打开模块。
- 分开显示 Hook 接入与配置读取状态，首次读取失败和沿用进程缓存不再混同于配置关闭；不记录 UID、cookie 或评论。

更新后需在原有明确抖音作用域内强停并重开抖音，让框架加载新模块代码。权限和调用方验证保持不变；本地展示过滤，不改平台数据。

云端 Debug/Release 各 75 项测试通过，版本脚本 7 项通过，Release Lint 无问题。测试包含 Android JVM 组件和菜单辅助方法，不能替代实际系统或 Xposed 注入测试。
