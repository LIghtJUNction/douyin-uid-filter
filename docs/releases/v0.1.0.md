# v0.1.0 预发布

首个开源版本，包含抖音数字 UID 评论过滤模块、独立设置页和自动签名发布工作流。

## 包含内容

- 输入指定 UID，按字符串精确匹配评论作者。
- 主评论、已加载回复和引用正文的本地展示过滤。
- 不修改原始模型的展示副本，支持重新进入评论区后切换 UID 或关闭过滤。
- 独立评论会话计数、空尾页保持累计数、空页自动续查与重复游标保护。
- 仅允许模块自身和抖音读取配置；APK 不申请联网权限。
- Actions 一键 patch / minor / major / custom bump，在签名构建和检查成功后推送标签并发布。

## 验证状态

58 项功能测试在 Debug 与 Release 配置下均通过，版本脚本 7 项测试通过，Release Lint 无错误或警告。

当前适配模型来自抖音 41.2.0 / 410201。真机在构建期间断开，**本版本尚未完成安装、框架注入与真实评论区效果验收**，因此标记为预发布。具体检查和待测场景见 [验收记录](https://github.com/LIghtJUNction/douyin-uid-filter/blob/v0.1.0/docs/device-validation.md)。

安装后需要在 LSPosed / Vector 中启用模块，作用域选择 `com.ss.android.ugc.aweme`，强行停止并重新打开抖音，再配置 UID。

本地过滤范围为已取得的评论数据；空页每次最多自动续查 32 页，隐藏且未加载的回复不在本地数据中。
